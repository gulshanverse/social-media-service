# Code of Conduct

## Purpose

College Confession is maintained by people with different backgrounds, experiences, and technical perspectives. This code establishes the conduct expected in issues, pull requests, reviews, discussions, and other project spaces.

## Expected behavior

Participants are expected to:

- Communicate respectfully and assume good faith.
- Focus criticism on technical decisions, behavior, and evidence rather than people.
- Give useful, specific feedback and explain relevant trade-offs.
- Respect privacy and avoid publishing personal information, credentials, or private correspondence.
- Keep discussions relevant to the project and make space for different viewpoints.
- Follow repository security practices and report vulnerabilities privately.

## Unacceptable behavior

The following conduct is not acceptable:

- Harassment, discrimination, threats, intimidation, or targeted personal attacks.
- Sexualized language or imagery in project spaces, unwanted advances, or sexual attention.
- Doxxing, publication of private information, or disclosure of credentials and security-sensitive data.
- Trolling, deliberate disruption, impersonation, or sustained off-topic activity.
- Retaliation against someone who raises a concern or reports a violation.
- Any other conduct that would reasonably make a participant feel unsafe or unable to contribute.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this standard. They may remove or edit comments, close discussions, request changes, restrict participation, or remove access when conduct violates this code. The response will be proportionate to the behavior and its impact.

## Reporting

Report unacceptable behavior to the project maintainers through a private GitHub communication channel. Include the relevant links, a concise description of what occurred, and any context needed to investigate. Do not include passwords, access tokens, or other credentials in a report.

Reports will be handled as confidentially as practical. The project will not retaliate against a person who makes a good-faith report.

## Scope

This code applies within project repositories, issue and pull-request discussions, project-managed communication channels, and any setting where a participant is representing the project.
