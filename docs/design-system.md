# Design system

The visual foundation uses `#070A12` as the base, `#101522` as surface, `#151C2B` as card, white text, muted gray text, and a controlled accent palette of pink, orange, purple, blue, cyan, green, lime, and gold. Gradients are reserved for primary actions and confession themes. The UI is mobile-first, high-contrast, keyboard-visible, and brand-led rather than enterprise-generic.
