# Premium Confession Sharing Experience

- [ ] **Responsive sharing surface:** Extend the existing detail-page ShareMenu in place. On desktop, clicking Share opens a connected floating glass panel near the trigger with the exact order Instagram, WhatsApp, Snapchat, Facebook, Copy Link, More. On mobile, clicking Share opens a safe-area-aware bottom sheet with a drag handle, dark backdrop, close button, and horizontally scrollable options that do not shrink below comfortable touch targets. The confession remains visible and the original confession card is unchanged.
- [ ] **Lifecycle and accessibility:** Share toggles open/closed; X, outside click, Escape, and mobile downward drag from the handle close it. Prevent background scroll while the sheet is open, restore scroll state on close/unmount, restore focus to the trigger, expose dialog/button state with ARIA, provide visible focus states, respect reduced motion, prevent duplicate actions, and stop panel gestures from entering confession carousel navigation.
- [ ] **Platform actions:** Instagram and Snapchat copy the exact current confession URL first, show honest copy-first guidance, and expose explicit open-app actions; WhatsApp opens an encoded composer with `Someone shared a confession with you! ❤️ Check it out 👀` plus the direct URL; Facebook opens its supported share dialog with the direct URL; Copy Link copies the URL and keeps the panel open; More uses `navigator.share` with title, text, and URL, keeping the panel open on cancellation and using Copy Link fallback when unsupported.
- [ ] **Failure handling:** Clipboard failures must not show false success. Show a useful status and a selectable manual-copy fallback. Popup blocking or unavailable native share must be communicated without claiming the post/message was sent.
- [ ] **Canonical metadata:** Every action uses `https://www.confessions.live/confessions/:publicId` without stale query parameters. Public confession metadata must remain published-only and non-indexable as currently configured, but should include confession-specific title/description, canonical URL, `og:type`, `og:url`, `og:image`, and Twitter card fields using the existing dynamic preview route.
- [ ] **Regression protection:** Add focused ShareMenu tests for open/close lifecycle, canonical URL destinations, clipboard success/failure, Instagram/Snapchat copy-first flows, native-share success/cancel/fallback, and duplicate-action protection. Run focused tests, full tests, lint, typecheck, formatting check, and production build. Do not modify confession-card source, APIs, database schema, or unrelated product areas.
- [ ] **Review-only Git workflow:** Keep changes on `feat/premium-confession-sharing` from `main`; inspect the final diff, commit relevant files, and open a PR against `main` if GitHub credentials are available. Do not merge or deploy.
